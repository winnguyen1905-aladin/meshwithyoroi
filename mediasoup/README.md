# Mediasoup Base Structure

This directory contains the base structure for Mediasoup integration (client-only). Files are placeholders without implementation logic.

Structure:
- `index.ts` – entry point for mediasoup exports
- `constants.ts` – shared constants for mediasoup layer
- `types.ts` – shared TypeScript types for mediasoup layer
- `client/index.ts` – client-side entry surface
